# 🌍 Entorno del proyecto

En este directorio se guardan los diferentes archivos necesarios para la configuración de un entorno facil de realizar y eficaz para el uso del programa

## ⚙️ .env.example

Archivo con el entorno de ejemplo de trabajo. Es necesario indicar los datos no rellenados o que contengan un placeholder

## ✅ requirements.txt

Archivo con los paquetes requeridos a instalar para el correcto funcionamiento del programa. Puede instalarlo con:

```bash
pip install -r requirements
```
